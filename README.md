# Hanania Meseret - Portfolio Website

A clean, modern, and responsive personal portfolio showcasing software engineering projects, UI/UX design work, technical skills, and experience.

## 🚀 Live Demo

- **URL:** [https://hanania16.github.io](https://hanania16.github.io)

## 📁 Project Structure

```text
.
├── assets/
│   ├── css/
│   │   └── style.css       # Clean, modular stylesheet with CSS custom properties
│   ├── js/
│   │   └── script.js       # Dynamic rendering, animations, & interactivity
│   └── images/
```

---

## 🛠️ Built With

- **HTML5:** Semantic markup, accessibility (ARIA attributes), SEO-friendly meta tags.
- **CSS3:** Modern flexbox & CSS grid layout, CSS custom properties, responsive design, smooth animations.
- **JavaScript (ES6+):** Dynamic data-driven components (Skills, Experience, Projects), scroll triggers, and touch-friendly mobile navigation.
- **Google Fonts:** Poppins & Preahvihear.

## 💻 Local Development

To run this site locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hanania16/hanania16.github.io.git
   cd hanania16.github.io
   ```

2. **Start a local development server:**
   ```bash
   # Using Python 3:
   python3 -m http.server 8000

   # Or using Node:
   npx serve .
   ```

3. **Open in your browser:**
   Visit `http://localhost:8000`
